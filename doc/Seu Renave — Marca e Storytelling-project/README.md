# Seu Renave — Marca e Storytelling — entire project

This project’s pages, files, and uploads as this browser tab had them at export.
Anything left out is listed below.

## Contents

### Logo

- `Main.dc.html` — Capa da marca
- `Conceitos.dc.html` — Logo oficial — anatomia
- `LogoVersoes.dc.html` — Versões do logo
- `LogoUso.dc.html` — Uso do logo
- `LogoEstilos.dc.html` — Estilos e expressões
- `Logo.dc.html` — Componente — Logo

### Sistema visual

- `Cores.dc.html` — Cores
- `Tipografia.dc.html` — Tipografia
- `Iconografia.dc.html` — Iconografia e grafismos

### Storytelling

- `Manifesto.dc.html` — Manifesto e propósito
- `Narrativa.dc.html` — Narrativa — storyboard
- `Voz.dc.html` — Tom de voz e taglines
- `Pilares.dc.html` — Pilares de valor

### Aplicações

- `AppIcon.dc.html` — Ícone de app, splash e login
- `Landing.dc.html` — Landing page
- `Papelaria.dc.html` — Papelaria
- `Social.dc.html` — Redes sociais
- `Slide.dc.html` — Pitch deck

### Other files

- `canvas.json` — the canvas: its pages, where each artboard sits, its notes and shapes
- `_runtime/` — what runs the pages in a browser; not part of the design

## Viewing

To view a page, start a local web server in this folder (for example `python3 -m http.server`), then open an artboard’s `.dc.html` file through it. Opening the file directly may not work, because some browsers block its scripts.

## Left out of this export

The export never includes hidden files (files whose names start with a dot) or
files the editor keeps for its own use.
